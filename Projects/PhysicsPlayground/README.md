# Physics Playground

A small sample game for the Lumen engine.

| Key | Action |
|---|---|
| W A S D / arrows | roll the red ball |
| Space | jump (when on the ground) |
| E | drop an orange ball above the player |
| Esc | quit |

Everything here is plain data: `game.lumen` (project settings), `scene.json` (entities, components and the `Ball`
prefab) and the Lua scripts embedded in the scene.
